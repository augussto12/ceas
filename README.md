# SocioEducativo CEAS
Sitio informativo desarrollado con React + Vite.

## Scripts
- `npm run dev` → modo desarrollo
- `npm run build` → genera los archivos para producción
- `npm run preview` → previsualiza el build

## Estructura
- `/components`: Header, Footer, etc.
- `/pages`: Home, News, NewsDetail, AboutUs
- `/data`: Contenido de las noticias
